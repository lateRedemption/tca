# Book Catalog

## Sobre o projeto

O **Book Catalog** é um projeto desenvolvido como Trabalho de Conclusão de Ano (TCA), com o objetivo de aplicar na prática os conhecimentos adquiridos durante o curso.

A aplicação permite pesquisar livros, visualizar suas informações, criar uma conta, favoritar livros e adicionar observações pessoais aos favoritos.

## Tecnologias utilizadas

- **React** — construção da interface.
- **TypeScript** — tipagem e organização do código.
- **Vite** — ferramenta de desenvolvimento e build.
- **React Router** — navegação entre páginas.
- **Supabase** — autenticação e banco de dados PostgreSQL.
- **Google Books API** — pesquisa e obtenção de informações sobre livros.
- **CSS** — estilização da aplicação.

## Objetivo

Desenvolver uma aplicação web funcional, colocando em prática conceitos de desenvolvimento frontend, integração com APIs externas, autenticação e operações CRUD em banco de dados.
